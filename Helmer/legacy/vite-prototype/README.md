# Legacy Vite Prototype

This directory contains the original single-page React + Vite prototype created during early MVP testing.

### Active Architecture
The production Helmer application runs on **Next.js 15 (App Router)**:
- Pages & Routes: `app/`
- UI Components: `components/`
- Shared Client Libraries: `lib/`
- Agent Engine & Tools: `server/`
- Background Task Worker: `worker/`
- Database Schema: `prisma/`

This folder is preserved for reference.
