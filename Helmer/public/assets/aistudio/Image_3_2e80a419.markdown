## Brand & Style

This design system expresses calm authority, precision, and ambient technological poise. Designed for autonomous AI agent orchestration, it departs from chaotic, hyper-dense developer interfaces in favor of an airy, luminous, Apple-inspired aesthetic where complex automation feels quiet, effortless, and entirely under human control.

### Brand Personality & Emotional Impact
- **Effortless Mastery:** Complex multi-agent executions appear serene and structured rather than overwhelming.
- **Precision Observability:** High legibility, delicate technical metrics, and luminous indicators convey uncompromised fidelity.
- **Tactile Calm:** Deep navy and near-black canvases paired with muted teals remove cognitive fatigue during critical agent steering and intervention.

### Dual-Theme Philosophy
The system bridges two operational modes:
1. **Light Mode (Marketing & Overview):** Soft off-white canvases (`#F4F6FA`) with faint radial pale-blue glow and concentric range lines, evocative of architectural drafting paper and aerospace navigational blueprints.
2. **Dark Glass Mode (Pro Console, Tracing & Live Steering):** Deep space canvas (`#0A0B0D`) layered with smoked translucent glass surfaces, edge-lit specular boundaries, and glowing teal accents for focus under continuous operation.

## Colors

The palette relies on a single signature cyan-teal accent scaled dynamically across environments, anchored by deep slate-navies and crisp light surfaces.

### Primary Accents
- **Dark Mode Primary (Luminous Teal):** `#4CC3CC` — high-visibility operational status, cursor points, active execution lines, and primary callouts on dark panels.
- **Light Mode Primary (Deep Calm Teal):** `#0E7C86` — grounded interactive anchors, verified agent tokens, and high-contrast headlines against light surfaces.

### Canvas & Structural Neutrals
- **Dark Canvas:** `#0A0B0D` base with card surfaces at `rgba(18, 22, 28, 0.70)`.
- **Dark Borders & Separators:** `rgba(255, 255, 255, 0.08)` for container boundaries; `rgba(76, 195, 204, 0.25)` for focused states.
- **Dark Text System:** `#F1F5F9` (Primary), `#94A3B8` (Muted / Secondary), `#475569` (Tertiary / Metadata).
- **Light Canvas:** `#F4F6FA` base with card surfaces at `rgba(255, 255, 255, 0.75)`.
- **Light Borders & Separators:** `rgba(226, 232, 240, 0.80)`.
- **Light Text System:** `#0B1F3A` (Primary Navy), `#334155` (Slate Secondary), `#64748B` (Subtle).

### Observability & Runtime Semantics
- **Running / Active / Pass:** Emerald `#10B981` (Surface glow: `rgba(16, 185, 129, 0.15)`).
- **Warning / Steer Intervention Needed:** Amber `#F59E0B` (Surface glow: `rgba(245, 158, 11, 0.15)`).
- **Error / Kill-Switch / Policy Trip:** Rose Crimson `#EF4444` (Surface glow: `rgba(239, 68, 68, 0.15)`).
- **Telemetry Hash / Determinism Indicator:** Indigo Slate `#6366F1`.

## Typography

The typography couples the engineering discipline of `Geist` with the editorial grace of `Playfair Display` (italicized). This dual voice creates tension between raw computational ability and curated human taste.

### Hierarchy & Editorial Accents
- **Modern Headlines:** Set in `Geist` at tight tracking (`-0.03em` to `-0.035em`) to evoke product launch clarity and architectural poise.
- **Editorial Emphasis:** Highlighted words within major marketing and dashboard hero headers switch seamlessly to `Playfair Display Italic`. Use this sparingly—maximum one or two words per headline (e.g., "Autonomous execution, *uncompromising* clarity").
- **Telemetry & Hashes:** Set strictly in `JetBrains Mono` for log streams, agent state hashes, token expenditures, and parameter inputs.

## Layout & Spacing

The layout is structured around an airy 12-column dynamic grid governed by generous negative space. Data density is achieved through refined component hierarchy rather than compacting margins.

### Breakpoints & Reflow Rules
- **Desktop (≥ 1280px):** 12-column grid, `margin-desktop` (3rem), `gutter-desktop` (2rem). Console views support a triple-split layout: Left Navigation & Agent Fleet (280px fixed), Center Trajectory View (fluid), Right Inspection & Steering Deck (400px fixed).
- **Tablet (768px – 1279px):** 8-column grid, 1.5rem gutters. The right inspection drawer shifts into an overlay glass sheet accessible via status pill toggles.
- **Mobile (< 768px):** 4-column grid, 1rem margin, 1rem gutter. Critical operational metrics convert to single-column vertical cards; telemetry feeds switch to collapsible timeline segments.

## Elevation & Depth

Visual depth is achieved through optical glass stratification rather than drop shadows. Surfaces appear as suspended frosted lenses hovering over subtle directional light fields.

### Layer Architecture
- **Layer 0 (Underlay Ground):** Radial atmospheric wash. In Light Mode, `#F4F6FA` with concentric rings centered behind hero milestones. In Dark Mode, `#0A0B0D` with a diffuse cyan bloom (`rgba(76, 195, 204, 0.07)`, 300px blur radius).
- **Layer 1 (Card & Module Shells):** Frosted glass panels.
  - *Light Mode:* Background `rgba(255, 255, 255, 0.72)`, backdrop filter `blur(20px)`, border `1px solid rgba(226, 232, 240, 0.70)`.
  - *Dark Mode:* Background `rgba(18, 22, 28, 0.70)`, backdrop filter `blur(24px)`, border `1px solid rgba(255, 255, 255, 0.08)`.
- **Layer 2 (Floating Popovers, Steer Controls, Modals):**
  - *Dark Mode:* Background `rgba(26, 32, 44, 0.85)`, backdrop filter `blur(32px)`, border `1px solid rgba(255, 255, 255, 0.15)`, ambient downward shadow `0 20px 40px -15px rgba(0, 0, 0, 0.7)`.
  - *Light Mode:* Background `rgba(255, 255, 255, 0.95)`, backdrop filter `blur(24px)`, border `1px solid rgba(14, 124, 134, 0.15)`, ambient downward shadow `0 20px 35px -10px rgba(11, 31, 58, 0.08)`.

## Shapes

The design uses a dual-geometry signature: expansive **20px rounded rectangles** for bounding enclosures and data modules, paired with pure **continuous pill shapes** for buttons, execution chips, and status nodes.

### Boundary Matrix
- **Data Containers & Glass Cards:** Strictly `20px` radius. Creates a soft, tailored viewport framing complex graph structures.
- **Action Controls & Status Badges:** Pill radius (`9999px`). Yields high touch confidence and frictionless visual scanning across linear timeline chains.
- **Nested Inner Items:** Inner metric tiles and sub-panels within glass cards scale to `12px` to preserve geometric harmony with the `20px` container.

## Components

### Buttons
- **Primary Pill:** In Dark Mode: solid near-white `#F1F5F9` background, `#0A0B0D` text, bold `Geist` 14px, pill-shaped (`9999px`). On hover, soft cyan halo (`box-shadow: 0 0 20px rgba(76, 195, 204, 0.35)`). In Light Mode: solid `#0E7C86` background, `#FFFFFF` text.
- **Secondary Glass Pill:** Semi-transparent fill (`rgba(255, 255, 255, 0.05)` dark / `rgba(255, 255, 255, 0.8)` light), 1px border (`rgba(255, 255, 255, 0.12)` dark / `rgba(226, 232, 240, 0.9)` light), matching typography.
- **Destructive / E-Stop (Kill Switch):** Deep crimson glass with high-intensity border (`#EF4444`). Active hover triggers pulsating red edge sheen.

### Glass Cards
- All cards feature a continuous `20px` border radius, frosted backdrop blur, and 1px hairline border.
- Cards maintain inner padding aligned to `space-lg` (1.5rem).
- Outer borders capture subtle directional gradients: lighter on the top edge (simulating overhead ambient luminescence), fading toward the lower edge.

### Status Chips & Badges
- Pill-shaped (`9999px`), height `24px`, inner padding `0 10px`.
- Composed of an 6px breathing dot (with CSS keyframe pulse for active states) and uppercase `mono-label` font.
- Variants:
  - *Running:* Emerald text `#10B981`, emerald fill `rgba(16, 185, 129, 0.10)`.
  - *Steering Required:* Amber text `#F59E0B`, amber fill `rgba(245, 158, 11, 0.10)`.
  - *Halted / Error:* Red text `#EF4444`, red fill `rgba(239, 68, 68, 0.10)`.

### Hash Chains & Execution Nodes
- Compact monospace inline capsules displaying cryptographic run proofs, agent session IDs, and seed nonces.
- Set in `JetBrains Mono` 11px with muted backgrounds (`rgba(255, 255, 255, 0.04)`), clickable with one-click copy confirmation tooltips.

### Timeline Trackers (Execution Graph)
- Vertical and horizontal trace tracks rendered with `1px` translucent connectors.
- Completed agent steps appear as solid cyan-teal nodes with connecting lines transitioning from faded slate to vivid accent color.
- Branching decisions render with curved SVG bezier lines conforming to subtle glowing dropoffs.

### Form Inputs & Parameter Sliders
- Input fields leverage `12px` rounded glass beds, `1px` structural borders, and monospaced placeholder values.
- Interactive steering sliders use `4px` tall tracks with glowing teal pill thumbs, offering live agent autonomy throttle controls (e.g., Temperature, Confidence Floor, Loop Limits).
